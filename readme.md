# Aplicación de Tareas

Aplicación web sencilla para organizar tus pendientes. Puedes crear tareas con título, fecha y descripción, editarlas y eliminarlas. Las tareas se guardan en el almacenamiento local del navegador (`localStorage`), así que permanecen disponibles en el mismo navegador y dispositivo.

## Funcionalidades

- Crear tareas con título, fecha opcional y descripción opcional.
- Editar y eliminar tareas.
- Confirmar antes de descartar cambios sin guardar.
- Guardar las tareas en el navegador sin necesidad de una cuenta o servidor.

## Cómo ejecutarla

No requiere instalación de dependencias ni proceso de compilación. Abre `index.html` directamente en un navegador. También puedes servir la carpeta con cualquier servidor estático local.

## Archivos principales

- `index.html`: estructura de la aplicación y metadatos de la página.
- `styles.css`: estilos y diseño adaptable.
- `index.js`: funciones de tareas y persistencia en `localStorage`.
- `icon/LogoVanActualizado.png`: icono de la pestaña del navegador.

## Tecnologías

HTML, CSS y JavaScript nativos.
